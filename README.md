# Simple Calculator  
A basic calculator built using **HTML, CSS, and JavaScript** that performs arithmetic operations such as addition, subtraction, multiplication, and division.  

## Features  
✔ Performs basic arithmetic operations: `+`, `-`, `*`, `/`  
✔ Responsive design  
✔ User-friendly interface  
✔ Real-time calculations  

## Technologies Used  
- HTML  
- CSS  
- JavaScript  

## How to Use  
1. Open the calculator in your browser: **[Simple Calculator](https://simple-calculator-omega-mocha.vercel.app/)**  
2. Use the number buttons to enter values.  
3. Click on an operator (`+`, `-`, `×`, `÷`).  
4. Enter the second number.  
5. Press `=` to see the result.  
6. Use the `C` button to clear the input.
